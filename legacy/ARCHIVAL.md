# Legacy Codebase — Archival Reference

This directory contains the **v1.0.4 BBT Fertility Tracker** (Flask-based), the predecessor to Byrd Health.

It is preserved for historical reference only. No code in this directory is:
- Imported by the current application
- Deployed in production
- Maintained or supported

The current codebase is a complete rewrite (FastAPI + React + TypeScript) located in `packages/` and `frontend/`.

For migration from legacy data, see `tools/legacy-migrate/`.
